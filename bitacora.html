Bitácora de Desarrollo

Registro cronológico de los desafíos, decisiones y la evolución del Grupo 5B.

Etapa 1: Organización

Decisiones: Definimos los roles iniciales y seleccionamos la temática de H.P. Lovecraft (Terror Cósmico) para la identidad visual.

Dificultades: Ausencia temporal de dos integrantes. Vasko y Sergio tomamos el liderazgo operativo para estructurar el proyecto completo y no retrasar la entrega.

Etapa 2: Diseño e Identidad Visual

Decisiones: Sergio definiw una paleta de colores oscuros ("Negro abisal" y "Verde Cthulhu") usando variables CSS para mantener la consistencia en todas las páginas.

Etapa 3: Desarrollo (HTML, CSS y JS)

Decisiones: Implementamos interacciones independientes con JavaScript (Medidor de Cordura en la Home, Mecanismo del Necronomicón en el perfil de Sergio y el Portal Dimensional en el de Vasko).
