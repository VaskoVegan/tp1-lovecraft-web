Diario de Expedición

Un registro prolijo de los pergaminos de código desenterrados, los desafíos que pusieron a prueba nuestra cordura y la evolución técnica del Grupo 5B.

01
📜

ETAPA 1: CONGESTIÓN Y ROLES

Decisiones de Proyecto: Leímos la consigna en conjunto y distribuimos los roles oficiales de la cátedra. Adoptamos la temática de H.P. Lovecraft para darle una identidad visual disruptiva al sitio.

Dificultades Afrontadas: Ausencia temporal de dos investigadores (Álvaro y Juance). Vasko y Sergio tomamos la posta operativa para crear la estructura base modular, garantizando que el proyecto avance sin retrasos.

02
🎨

ETAPA 2: ARQUITECTURA VISUAL

Decisiones de Diseño: Sergio diseñó la guía de estilos inmersiva. Combinamos las fuentes tipográficas 'Cinzel' y 'IM Fell English' para lograr un aspecto de manuscrito antiguo, regulado bajo un sistema de variables de CSS adaptativo para evitar desbordes.

03
⚡

ETAPA 3: DESATANDO EL DOM

Decisiones de Código: Estructuramos de forma limpia los perfiles enlazando discos y películas con hipervínculos externos funcionales hacia Spotify e IMDb. Programamos interacciones independientes en JavaScript para manipular el DOM de manera creativa en cada expediente.

04
📱

ETAPA 4: CONTROL RESPONSIVE

Testing y Calidad: Validamos de forma estricta los tres breakpoints obligatorios (400px, 900px y 1200px) mediante las herramientas de desarrollo del navegador, asegurando que las grillas colapsen correctamente en dispositivos móviles.
